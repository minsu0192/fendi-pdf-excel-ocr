# FENDI PDF Excel OCR

FENDI 과세가격 결정자료 제출 요청 공문의 4~7페이지를 브라우저 OCR로 읽어 Excel 파일로 변환하는 GitHub Pages 웹앱입니다.

## 특징

- PDF.js로 PDF 페이지 렌더링
- Tesseract.js `kor+eng` OCR
- 고정 양식의 열 좌표 기반 행 추출
- OCR 신뢰도가 낮은 행 검토 표시
- SheetJS를 이용한 `.xlsx` 생성
- 모든 처리가 브라우저에서 이루어지며 PDF는 서버에 업로드되지 않음

## 사용법

1. 웹페이지에 PDF를 선택합니다.
2. 기본 페이지 범위 `4-7`을 확인합니다.
3. `엑셀 추출 시작`을 누릅니다.
4. 결과를 검토하고 엑셀을 내려받습니다.

처음 실행할 때 한국어·영어 OCR 모델을 내려받으므로 인터넷 연결이 필요합니다. OCR 결과는 스캔 상태에 따라 달라질 수 있으므로 `OCR검토필요` 표시 행을 원본과 대조하세요.

## 로컬 테스트

정적 파일이므로 간단한 HTTP 서버에서 실행할 수 있습니다.

```bash
python -m http.server 8000
```

그 후 `http://localhost:8000`에 접속합니다.
